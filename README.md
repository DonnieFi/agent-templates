# Agent Templates

A curated collection of modular, production-ready agent templates for OpenClaw and autonomous agent frameworks.

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/DonnieFi/agent-templates.git
cd agent-templates
```

### 2. Select and Copy a Template

Browse the `templates/` directory and copy the template you need to your project workspace:

```bash
cp -r templates/starter-agent /path/to/your-project/my-agent
cd /path/to/your-project/my-agent
```

### 3. Configure

Each template includes its own `README.md` and configuration file (`agent.json`). Edit the agent configuration and prompt files to customize behavior and tool access.
