# Starter Agent Template

A minimalist scaffold for creating autonomous agent workflows.

## Files

- `agent.json`: Agent metadata, model parameters, and tool configurations.
- `prompts/system.md`: Core system prompt defining behavior, tone, and constraints.

## Setup

1. Copy this folder into your agent project directory:
   ```bash
   cp -r templates/starter-agent /path/to/destination
   ```
2. Adjust `agent.json` and customize `prompts/system.md`.
